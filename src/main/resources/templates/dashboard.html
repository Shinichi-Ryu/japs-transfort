System Architecture Summary

Japs Transfort is built following a clean 3-tier MVC pattern designed for modularity, strict security separation, and maintainability.

Security & Authentication

Role-Based Access Control (Admin, Staff, Warehouse, Reseller) with BCrypt-hashed credentials and CSRF protection.

Database Integrity

PostgreSQL 18 native schema with Hibernate validation (ddl-auto=validate) and soft deletion.

Financial Precision

All money, prices, balances, and discounts utilize BigDecimal to prevent IEEE floating-point errors.

Layer Isolation

Controllers handle HTTP routing, Services encapsulate business rules, and Repositories handle data persistence.
